# ADR 0002：采用后端输入桥接层与 0.1 纵向切片

状态：已接受

日期：2026-08-04

## 背景

NetHack 的传统界面以字符输入、提示和菜单为中心。GodotHack 需要现代 Godot 界面，同时必须保留 NetHack 后端作为规则权威。

如果 Godot 前端把每个现代界面动作翻译成原生 NetHack 字符串，前端会承担命令绑定、提示顺序和临时菜单字母的知识。这会形成第二套输入语义，并使测试核心与 NetHack 核心难以共享前端协议。

## 决策

采用加强版方案二。

客户端发送协议输入；后端输入调度层持有活动提示、校验输入，并将其交给 NetHack 桥接层或测试核心桥接层。菜单选择使用后端生成的稳定菜单项标识和提示标识。

0.1 使用完整视图快照、四种提示类型和一个确定性的测试核心纵向流程。具体范围由 MVP-0.1-cn.md 和 PROTOCOL-cn.md 定义。

## 影响

- 命令语义、规则、回合消耗和最终输入校验集中在后端。
- Godot 可以使用按钮、列表滚动和文本框，而不依赖终端布局。
- 测试核心能复用同一客户端和同一协议。
- 后端需要实现明确的提示状态机和 NetHack 输入桥接层。
- 后续支持 Ctrl、Meta、地图选点和复杂命令时，需要扩展协议并更新验收范围。
