# GodotHack Project Docs

This directory contains GodotHack-specific documentation. It is separate from
the upstream NetHack `doc/` directory on purpose.

Start here:

- `ARCHITECTURE.md` describes the frontend/backend shape of the project.
- `PROTOCOL.md` documents the TCP JSON session contract.
- `AI_GUIDE.md` gives AI agents and human collaborators the project context
  needed for useful changes.
- `WORKLOG.md` records curated development history and decisions.
- `adr/` stores architecture decision records.
