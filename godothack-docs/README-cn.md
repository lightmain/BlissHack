# GodotHack 项目文档

这个目录存放 GodotHack 专属文档。它有意和上游 NetHack 的 `doc/` 目录分开。

建议从这些文件开始阅读：

- `ARCHITECTURE.md` 描述项目的前后端结构。
- `BUILDING.md` 记录已验证的 NetHack 5.0.0 Windows 基线构建流程。
- `PROTOCOL.md` 记录 TCP JSON session 的通信契约。
- `AI_GUIDE.md` 为 AI agent 和人类协作者提供项目上下文，帮助他们做出有用的修改。
- `WORKLOG.md` 记录整理后的开发历史和关键决策。
- `adr/` 存放架构决策记录。
