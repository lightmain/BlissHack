# BlissHack alpha-2.1 计划

## 状态

实现与自动门禁已完成，等待人工验收。尚未 push 或部署。

## 目标

alpha-2.1 收敛游戏内键盘焦点与 Below HUD 布局，不改变 NetHack 核心规则、
存档格式或 profile schema。

## 范围

### 1. 永久背包不取得游戏键盘所有权

- 普通游戏状态下，永久背包或其中物品即使持有 DOM focus，`hjkl` 等游戏按键
  仍发送给 NetHack。
- 永久背包中的物品 accelerator 字符继续显示，但不能通过字符键选择或聚焦
  物品；折叠按钮和物品动作只由鼠标操作。
- `i` 命令打开的核心背包菜单保持原有键盘 accelerator、方向键和确认行为。
- 核心菜单、文本输入、设置等真正需要键盘所有权的界面不受影响。

### 2. 重做 Below HUD

- 消息区域保持在 HUD 顶部。
- 地图位于消息区域下方，水平居中、顶部对齐，不缩放。
- 地图 Grid 行按内部固定 80×21 地图的固有高度布局，不再使用 `1fr` 吞掉
  剩余高度。
- 地图下方由状态栏和永久背包共同占据剩余高度：状态栏在左、宽度较窄；
  永久背包在右并取得剩余宽度。
- 状态栏允许在窄列中增加换行；状态栏与永久背包所在行具有明确最小高度。
- 禁用或折叠永久背包时，Grid 不保留无用途的空白轨道。
- 极矮 viewport 由 Below Grid 自身提供纵向滚动；在 320px 最小宽度下状态栏
  与背包各保留 10rem，不产生页面横向 overflow。
- Right 布局保持现状。

### 3. 移除地图默认焦点框

- 右键菜单关闭后仍可恢复地图 focus，保证键盘输入连续。
- 禁止浏览器在 `.nh-map-interaction` 上绘制默认蓝色 outline。
- 不新增临时焦点框；地图区域边界设计留给后续视觉迭代。

## 验收

- 聚焦永久背包容器、物品或折叠按钮后按 `j`，事件由游戏键盘处理，不触发
  永久背包字符导航。
- `i` 键背包仍可使用 accelerator 选择物品。
- Tiles 与 ASCII 在 1280×900、900×700 的 Below 布局中满足地图固有高度、
  水平居中、底部左右分栏、最小高度、无区域重叠和无页面 overflow。
- Right 布局几何不回归。
- 地图右键菜单执行或取消后恢复 focus，但不出现浏览器默认蓝框。

